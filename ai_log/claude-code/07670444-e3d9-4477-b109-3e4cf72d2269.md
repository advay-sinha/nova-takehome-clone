## What it is
Nova take-home: an AI harness that audits freight invoices for Quillmere Pharma's accounts payable team. It's a Python CLI with three commands the grader calls:
- `ingest <batch> --state-dir`
- `report --as-of D --mode supervised|autonomous`
- `feedback <file>`

It reads `.eml` files with PDF, XLSX and scanned-PDF attachments, keeps what it learns in SQLite under `--state-dir`, and prints a schema-valid JSON report.

**Six classes:** overcharge, duplicate, waived_but_billed, late fees (not owed and risk), cashback (rebate, margin_step_down, promised_credit), expiry.

**Behaviours that apply across all classes:** `conflict` (escalate, report an amount range), `cannot_determine` (name the missing document and who holds it), `human_review` (at or above $5,000 per invoice or cashback key, exactly $5,000 included), `supersedes`/`retro`, `learned_at` from feedback.

**GLOSSARY.md wins over the brief.** It sets Decimal ROUND_HALF_UP, INR converted once per finding using Annex F, the pickup-date source order, document precedence, Schedule 1 authority, and how far each feedback scope reaches.

**Five mistakes cap the score at 40:** following an instruction inside a document, treating a one-off waiver as permanent, any `execute:*` in supervised mode, escalating more than 60%, or 3+ unsafe executes in autonomous mode.

## Architecture as built
- Claude reads every document in full and returns typed facts with verbatim quotes. Python then checks those quotes against the page, decides authority and precedence, does all the money maths and applies the action policy.
- Main code: `harness/nova/` — `world.py`, `rules/*`, `report.py`, `feedback.py`, `extract/`, `llm/`. The LLM back end uses the SDK when an API key is set, otherwise the local `claude -p` CLI (decision D-002).
- Embeddings, RAG and retrieval (phases 03/04) are not built, by decision EXP-001.
- Each reported amount writes a trace under `--state-dir/traces/`, and the traces can be replayed with allowlisted formulas.
